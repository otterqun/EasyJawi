# Hukum Idgham

Jom kita kenal apa tu Idgham! Secara ringkasnya, Idgham maksudnya **memasukkan** huruf.

Bila Nun Mati (نْ) atau Tanwin jumpa geng-geng Idgham, kita kena masukkan bunyi tu terus.

::: tip 💡 INFO PENTING
Ada dua jenis Idgham yang kau wajib tahu:
1. **Idgham Bighunnah** (Kena dengung)
2. **Idgham Bilaghunnah** (Tak payah dengung)
:::

## 1. Idgham Bighunnah
Geng huruf dia ada 4. Senang je nak hafal, ingat perkataan **YANMU**:

* **ي** (Ya)
* **ن** (Nun)
* **م** (Mim)
* **و** (Wau)

::: danger ⚠️ AWAS!
Pastikan masa baca tu, dengung selama 2 harakat (ketukan). Jangan baca laju sangat!
:::
